# Теория и реализация алгоритмов поиска

В этой директории представлены различные алгоритмы поиска на языке C++. Каждый алгоритм имеет свою теоретическую основу, описание работы и соответствующую реализацию. Ниже приведены теоретические материалы и описание каждого алгоритма поиска.

## Основные понятия

Алгоритмы поиска — это алгоритмы, предназначенные для нахождения элемента в коллекции данных, такой как массив, список или другие структуры данных. В зависимости от структуры данных и того, как они организованы, существует несколько различных типов алгоритмов поиска, каждый из которых имеет свои особенности и области применения.

Алгоритмы поиска могут быть классифицированы на **поиск в неотсортированных данных** (например, линейный поиск) и **поиск в отсортированных данных** (например, двоичный поиск). Правильный выбор алгоритма поиска может существенно повлиять на скорость обработки данных.

---

### Определения

-   **Коллекция данных**: Множество элементов, в котором необходимо найти целевой элемент (массив, список, дерево и т. д.).
-   **Поиск**: Процесс нахождения целевого элемента в коллекции данных.
-   **Ключ**: Элемент, который требуется найти в коллекции.
-   **Алгоритм поиска**: Пошаговое описание действий, направленных на нахождение целевого элемента в коллекции.
-   **Сложность алгоритма**: Оценка того, сколько времени и памяти будет занимать выполнение алгоритма в зависимости от размера данных. Важно выделить два типа сложности:
-   **Время выполнения** (или временная сложность): Сколько времени потребуется для нахождения элемента.
-   **Используемая память** (или пространственная сложность): Сколько памяти потребуется для выполнения поиска.

---

### Характеристики алгоритмов поиска

1.  **Сложность**:
	-  **Лучшее время**: Как быстро работает алгоритм в идеальных условиях, когда данные уже отсортированы (или почти отсортированы).
	-  **Среднее время**: Ожидаемое время выполнения алгоритма на случайных данных.
	-  **Худшее время**: Время выполнения алгоритма в худшем случае (например, если данные отсортированы в обратном порядке).

2.  **Пространственная сложность**: Сколько дополнительной памяти требуется для выполнения алгоритма. Алгоритм может работать либо "на месте" (в пределах исходной структуры данных), либо требовать дополнительной памяти.

3.  **Стабильность**: Алгоритм сортировки называется стабильным, если при одинаковых значениях элементов их относительный порядок сохраняется. Например, если в списке людей с одинаковым возрастом их сортируют по имени, то люди с одинаковым возрастом будут располагаться в том же порядке, в котором они шли изначально.

---

### Оценка эффективности алгоритмов поиска

1.  **Время выполнения**:
	- $O(n^2)$ — плохо масштабируется на больших данных. Это характерно для сортировок, таких как пузырьковая сортировка и сортировка выбором.
	- $O(n \log n)$ — эффективный подход для большинства крупных коллекций данных. Например, быстрая сортировка и сортировка слиянием.
	- $O(n)$ — алгоритмы, такие как поразрядная сортировка, могут достигать линейной сложности при определённых условиях.
2.  **Память**:
	- Алгоритмы, такие как пузырьковая сортировка, сортировка вставками и сортировка выбором, часто используют $O(1)$ дополнительной памяти (сортировка на месте).
	- Алгоритмы, такие как сортировка слиянием, могут требовать $O(n)$ дополнительной памяти для хранения временных данных.
