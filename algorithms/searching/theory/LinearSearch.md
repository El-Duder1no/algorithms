# Linear Search

**Линейный поиск** — это алгоритм для нахождения элемента в списке, который проверяет каждый элемент в последовательности один за другим, начиная с первого. Алгоритм завершает поиск, когда находит целевой элемент или когда проверены все элементы в списке.

## Алгоритм

 1. Начинаем с первого элемента в списке.
 2. Сравниваем текущий элемент с целевым значением.
 3. Если элементы совпали, возвращаем индекс найденного элемента.
 4. Если элементы не совпали, переходим к следующему элементу в списке.
 5. Повторяем шаги 2-4, пока не найдем элемент или не проверим все элементы.
 6. Если элемент не найден в списке, возвращаем информацию о том, что элемент отсутствует.

## Пример

Предположим, нам нужно найти число 5 в следующем массиве - `[3, 8, 5, 12, 6]`
1.  Сравниваем первый элемент (`3`) с числом `5` — они не совпадают, продолжаем искать.
2.  Сравниваем второй элемент (`8`) с числом `5` — они не совпадают, продолжаем искать.
3.  Сравниваем третий элемент (`5`) с числом `5` — элементы совпали. Элемент найден на позиции `3` (нумерация с `1`).

**Результат:** элемент найден на позиции `3`.

## Сложность

-   **Время:** В худшем случае, когда элемент отсутствует или находится в конце списка, алгоритм проверяет все элементы. Время работы алгоритма — $O(n)$, где n — количество элементов в списке.
-   **Память:** Алгоритм работает на месте, не требуя дополнительной памяти, поэтому его пространственная сложность — $O(1)$.
