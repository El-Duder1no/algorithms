# Binary Search

**Двоичный поиск** — это алгоритм для нахождения элемента в отсортированном списке, который сужает диапазон поиска, деля его пополам на каждом шаге. Алгоритм завершает поиск, когда находит искомый элемент или когда диапазон поиска становится пустым.

## Алгоритм

1. Начинаем с двух индексов: `low`, который указывает на начало
    массива, и `high`, который указывает на конец массива.
2. Находим индекс середины массива: `mid = (low + high) // 2`. 
3. Сравниваем элемент в середине массива (`list[mid]`) с целевым значением.
4. Если элементы совпали, возвращаем индекс найденного элемента. 
5. Если элемент в середине массива меньше целевого значения, сдвигаем индекс `low` к `mid + 1` (поиск продолжается в правой части массива).
6. Если элемент в середине массива больше целевого значения, сдвигаем индекс `high` к `mid - 1` (поиск продолжается в левой части массива). 
7. Повторяем шаги 2-6, пока `low` не станет больше `high`.
8. Если элемент не найден, возвращаем информацию о том, что элемент отсутствует.

## Пример

Предположим, нам нужно найти число 6 в отсортированном массиве - `[1, 3, 5, 6, 8, 9]`

1.  Начальные индексы: `low = 0`, `high = 6`.
2.  `mid = (0 + 6) / 2 = 3`. Элемент в середине: `array[mid] = 5`.
    -   `5` меньше `6`, значит, продолжаем искать в правой части. Обновляем `low = 4`.
3.  Новый диапазон: `low = 4`, `high = 6`.
4.  `mid = (4 + 6) / 2 = 5`. Элемент в середине: `array[mid] = 8`.
    -   `8` больше `6`, значит, продолжаем искать в левой части. Обновляем `high = 4`.
5.  Новый диапазон: `low = 4`, `high = 4`.
6.  `mid = (4 + 4) / 2 = 4`. Элемент в середине: `array[mid] = 6`.
    -   Элемент совпал с целевым значением, возвращаем индекс `4`.

**Результат**: элемент найден на позиции `4` (нумерация с `1`).

## Псевдокод

    procedure BinarySearch(A, n, key)
	    A — отсортированный массив
	    n - размер массива
	    key — искомое значение

	    low = 1
	    high = n

	    while low <= high do
		    // Находим середину массива
	        mid = (low + high) // 2  

	        if A[mid] == key then
		        // Если значение найдено, возвращаем индекс
	            return mid
            end if
	        else if A[mid] < key then
		        // Если значение в середине меньше искомого, ищем справа
	            low = mid + 1
            end if 
	        else
		        // Если значение в середине больше искомого, ищем слева
	            high = mid - 1  
	    end while
		
		// Если элемент не найден, возвращаем -1 
	    return -1  
    end procedure

## Сложность

-   **Время:** Время работы алгоритма — $O(\log n)$, так как на каждом шаге диапазон поиска уменьшается в два раза, что значительно ускоряет поиск по сравнению с линейным.
-   **Пространственная сложность:** $O(1)$, поскольку алгоритм использует только несколько переменных для хранения индексов и не требует дополнительной памяти для работы.
