# Merge Sort

**Merge Sort** — это один из самых эффективных алгоритмов сортировки, основанный на принципе "разделяй и властвуй". Он рекурсивно разделяет массив на две части, сортирует их и затем сливает обратно в один отсортированный массив. Алгоритм является стабилизированным, т.е. не меняет порядок равных элементов.

## Пример

Рассмотрим пример сортировки массива  `[38, 27, 43, 3, 9, 82, 10]`:

**Шаг 1:**  Разделяем массив на две половины:  
Левый подмассив:  `[38, 27, 43]`  
Правый подмассив:  `[3, 9, 82, 10]`

**Шаг 2:**  Рекурсивно делим каждый подмассив:  
Левый подмассив  `[38, 27, 43]`  разделяется на  `[38]`  и  `[27, 43]`.  
Правый подмассив  `[3, 9, 82, 10]`  разделяется на  `[3, 9]`  и  `[82, 10]`.

**Шаг 3:**  Делаем еще одно разделение:  
Подмассив  `[27, 43]`  делится на  `[27]`  и  `[43]`.  
Подмассив  `[3, 9]`  делится на  `[3]`  и  `[9]`.  
Подмассив  `[82, 10]`  делится на  `[82]`  и  `[10]`.

Теперь все подмассивы состоят из одного элемента и отсортированы.

**Шаг 4:**  Начинаем процесс слияния:  
Сливаем подмассивы  `[27]`  и  `[43]`  в отсортированный массив  `[27, 43]`.  
Сливаем подмассивы  `[3]`  и  `[9]`  в отсортированный массив  `[3, 9]`.  
Сливаем подмассивы  `[82]`  и  `[10]`  в отсортированный массив  `[10, 82]`.

**Шаг 5:**  Теперь сливаем более крупные подмассивы:  
Сливаем подмассивы  `[38]`  и  `[27, 43]`  в отсортированный массив  `[27, 38, 43]`.  
Сливаем подмассивы  `[3, 9]`  и  `[10, 82]`  в отсортированный массив  `[3, 9, 10, 82]`.

**Шаг 6:**  Наконец, сливаем все части массива в один отсортированный массив:  
Сливаем  `[27, 38, 43]`  и  `[3, 9, 10, 82]`  в итоговый отсортированный массив  `[3, 9, 10, 27, 38, 43, 82]`.

Теперь весь массив отсортирован:  `[3, 9, 10, 27, 38, 43, 82]`.

## Алгоритм

    procedure MergeSort(A, low, high)
        A — массив
        low — индекс первого элемента
        high — индекс последнего элемента
    
        if low < high then
            mid = (low + high) div 2
            MergeSort(A, low, mid)  	 // Сортируем левую половину
            MergeSort(A, mid + 1, high)  // Сортируем правую половину
            Merge(A, low, mid, high)  	 // Сливаем отсортированные части
        end if
    end procedure
    
    procedure Merge(A, low, mid, high)
        A — массив
        low — индекс первого элемента
        mid — индекс середины
        high — индекс последнего элемента
    
        n1 = mid - low + 1  // Размер левой части
        n2 = high - mid     // Размер правой части
    
        // Создаем временные массивы
        L = new array of size n1
        R = new array of size n2
    
        for i = 1 to n1 do
            L[i] = A[low + i - 1]  // Копируем элементы в левый массив
        end for
    
        for i = 1 to n2 do
            R[i] = A[mid + i]  	   // Копируем элементы в правый массив
        end for
    
        i = 1  // Индекс для левого массива
        j = 1  // Индекс для правого массива
        k = low  // Индекс для исходного массива
    
        while i <= n1 and j <= n2 do
            if L[i] <= R[j] then
                A[k] = L[i]
                i = i + 1
            else
                A[k] = R[j]
                j = j + 1
            end if
            k = k + 1
        end while
    
        // Копируем оставшиеся элементы из левого массива, если они есть
        while i <= n1 do
            A[k] = L[i]
            i = i + 1
            k = k + 1
        end while
    
        // Копируем оставшиеся элементы из правого массива, если они есть
        while j <= n2 do
            A[k] = R[j]
            j = j + 1
            k = k + 1
        end while
    end procedure


# Сложность

-   Время: 
    - **Лучший случай:** O(n log n) — независимо от порядка элементов, каждый уровень рекурсии делит массив пополам, а на каждом уровне нужно пройти по всем элементам. 
    - **Средний случай**: O(n log n) — как и в лучшем случае, на каждом уровне рекурсии выполняются O(n) операций, а самих уровней log n. 
    - **Худший случай**: O(n log n) — как и в среднем, на каждом уровне выполняются O(n) операций, а самих уровней log n.
-   Память: O(n) для хранения временных массивов.
