# Heap Sort

**Heap Sort (пирамидальная сортировка)** — это эффективный алгоритм сортировки, который использует структуру данных «куча» (или **heap**). Алгоритм работает на принципе сортировки с использованием свойств кучи, где каждый родительский элемент больше (или меньше) своих потомков в зависимости от типа кучи (макс-куча или мин-куча).

## Пример

Рассмотрим пример сортировки массива  `[4, 10, 3, 5, 1]`  с использованием сортировки кучей:

**Шаг 1:**  Строим макс-кучу из массива:  
После построения макс-кучи:  `[10, 5, 3, 4, 1]`  
Куча теперь удовлетворяет свойству, что каждый родительский элемент больше своих потомков.

**Шаг 2:**  Извлекаем максимальный элемент (корень кучи,  `10`) и помещаем его в конец массива:  
Массив после перемещения максимального элемента:  `[1, 5, 3, 4, 10]`

Восстанавливаем кучу для оставшихся элементов:  
Массив после восстановления кучи:  `[5, 4, 3, 1, 10]`

**Шаг 3:**  Извлекаем следующий максимальный элемент (`5`) и помещаем его в конец массива:  
Массив после перемещения максимального элемента:  `[1, 4, 3, 5, 10]`

Восстанавливаем кучу для оставшихся элементов:  
Массив после восстановления кучи:  `[4, 1, 3, 5, 10]`

**Шаг 4:**  Извлекаем следующий максимальный элемент (`4`) и помещаем его в конец массива:  
Массив после перемещения максимального элемента:  `[3, 1, 4, 5, 10]`

Восстанавливаем кучу для оставшихся элементов:  
Массив после восстановления кучи:  `[3, 1, 4, 5, 10]`

**Шаг 5:**  Извлекаем следующий максимальный элемент (`3`) и помещаем его в конец массива:  
Массив после перемещения максимального элемента:  `[1, 3, 4, 5, 10]`

Восстанавливаем кучу для оставшихся элементов:  
Массив после восстановления кучи:  `[1, 3, 4, 5, 10]`

**Шаг 6:**  Извлекаем последний элемент (`1`) и получаем отсортированный массив:  
Итоговый отсортированный массив:  `[1, 3, 4, 5, 10]`

## Алгоритм

    procedure HeapSort(A, n)
        A — массив
        n — размер массива
    
        // Шаг 1: Строим макс-кучу
        for i = n div 2 to 1 do
            MaxHeapify(A, n, i)
        end for
    
        // Шаг 2: Извлечение элементов из кучи
        for i = n to 2 do
            swap A[1] and A[i]
            MaxHeapify(A, i - 1, 1)
        end for
    end procedure
    
    procedure MaxHeapify(A, n, i)
        A — массив
        n — размер кучи
        i — индекс текущего узла
    
        largest = i         // Допустим, текущий узел - наибольший
        left = 2 * i        // Левый дочерний узел
        right = 2 * i + 1   // Правый дочерний узел
    
        if left <= n and A[left] > A[largest] then
            largest = left
        end if
    
        if right <= n and A[right] > A[largest] then
            largest = right
        end if
    
        if largest != i then
            swap A[i] and A[largest]
            MaxHeapify(A, n, largest)
        end if
        end procedure

# Сложность

-   Время: 
    Время работы пирамидальной сортировки составляет $O(n log n)$ в любом случае, поскольку на каждом уровне нужно выполнить операцию восстановления кучи для всех элементов. 
    В худшем случае для каждого из n элементов выполняется операция восстановления кучи, которая требует $O(\log n)$ времени.
-   Память: $O(1)$, т.к. сортировка выполняется на месте без использования дополнительной памяти, кроме временных переменных для хранения индексов. Алгоритм не требует дополнительного массива, как, например, сортировка слиянием.
