# Bubble Sort

**Bubble Sort** — это алгоритм сортировки, который многократно проходит по списку, сравнивает соседние элементы и меняет их местами, если они находятся в неправильном порядке. Процесс повторяется до тех пор, пока список не будет отсортирован.

## Алгоритм

1.  **Инициализация**:
    -   На вход подается массив из  `n`  элементов.
2.  **Основной цикл**:
    -   Для каждого индекса  `i`  от  первого до предпоследнего элемента:
        -   Для каждого индекса  `j`  от  `0`  до  `последний элемент - i`:
            -   Сравниваем элементы  `arr[j]`  и  `arr[j+1]`.
            -   Если  `arr[j] > arr[j+1]`, меняем их местами.
        -   После каждого прохода внутреннего цикла наибольший элемент "всплывает" в конец массива.
3.  **Оптимизация**:
    -   Если во время прохода внутреннего цикла не было выполнено ни одного обмена, массив уже отсортирован, и алгоритм можно завершить досрочно.
4.  **Завершение**:
    -   После выполнения всех итераций массив становится полностью отсортированным.

Алгоритм завершает работу, когда на одном из проходов не происходит обменов — это означает, что все элементы находятся на своих местах.

## Пример
Предположим, у нас есть список чисел: `[5, 2, 9, 1, 5, 6]`. Начнём сортировку по алгоритму:

**1-й проход:**  
Сравниваем 5 и 2. `5 > 2`, меняем местами →  `[2, 5, 9, 1, 5, 6]`  
Сравниваем 5 и 9. `5 < 9`, не меняем местами →  `[2, 5, 9, 1, 5, 6]`  
Сравниваем 9 и 1. `9 > 1`, меняем местами →  `[2, 5, 1, 9, 5, 6]`  
Сравниваем 9 и 5. `9 > 5`, меняем местами →  `[2, 5, 1, 5, 9, 6]`  
Сравниваем 9 и 6. `9 > 6`, меняем местами →  `[2, 5, 1, 5, 6, 9]`  
После первого прохода массив выглядит как  `[2, 5, 1, 5, 6, 9]`

Наибольший элемент  `(9)`  оказался на последней позиции.

**2-й проход:**  
Сравниваем 2 и 5. `2 < 5`, не меняем местами →  `[2, 5, 1, 5, 6, 9]`  
Сравниваем 5 и 1. `5 > 1`, меняем местами →  `[2, 1, 5, 5, 6, 9]`  
Сравниваем 5 и 5. `5 = 5`, не меняем местами →  `[2, 1, 5, 5, 6, 9]`  
Сравниваем 5 и 6. `5 < 6`, не меняем местами →  `[2, 1, 5, 5, 6, 9]`

Теперь  `9`  все еще на последнем месте, и осталось отсортировать оставшуюся часть массива.

**3-й проход:**  
Сравниваем 2 и 1. `2 > 1`, меняем местами → `[1, 2, 5, 5, 6, 9]`  
Сравниваем 2 и 5. `2 < 5`, не меняем местами →  `[1, 2, 5, 5, 6, 9]`  
Сравниваем 5 и 5. `5 = 5`, не меняем местами →  `[1, 2, 5, 5, 6, 9]`

Теперь массив отсортирован:  `[1, 2, 5, 5, 6, 9]`

## Псевдокод
    procedure BubbleSort(A, n)
	    A — массив
	    n — размер массива
	    swapped = false
	    for i = 1 to n - 1 do
		    swapped = false
		    for j = 1 to n - i - i do
			    if A[i] > A[i + 1] then
				    swap A[i] and A[i + 1]
				    swapped = true
			    end if
		    end for
        end for
	end procedure

## Сложность

- Время:
  -   **Лучший случай**: $O(n)$ — если массив уже отсортирован, то алгоритм может пройти по нему один раз, не совершая никаких перестановок.
  -   **Средний случай**: $O(n^2)$ — обычно алгоритм выполняет $n-1$ проходов по массиву, и каждый проход требует $n-i$ сравнений, где $i$ — это индекс текущего прохода, $n$ - количество элементов в массиве.
  -   **Худший случай**: $O(n^2)$ — если массив отсортирован в обратном порядке, алгоритм выполнит наибольшее количество перестановок и сравнений.
- Память: $O(1)$, так как сортировка выполняется на месте.
