# Selection Sort

**Selection Sort** — это алгоритм сортировки, который работает по принципу последовательного выбора минимального (или максимального) элемента из неотсортированной части массива и перемещения его в отсортированную часть. Алгоритм минимизирует количество обменов, так как на каждом шаге происходит только один обмен.

## Алгоритм

1.  **Инициализация**:
    -   На вход подается массив из  `n`  элементов.
    -   Отсортированная часть массива изначально пуста, а неотсортированная часть — это весь массив.
2.  **Основной цикл**:
    -   Для каждого индекса  `i`  от  первого  до  предпоследнего элемента:
        -   Находим индекс минимального элемента в неотсортированной части массива (от  `i`  до  предпоследнего элемента).
        -   Меняем местами минимальный элемент с элементом на позиции  `i`.
        -   Теперь элемент на позиции  `i`  считается частью отсортированной части массива.
3.  **Завершение**:
    -   После выполнения всех итераций массив становится полностью отсортированным.

## Пример

Предположим, у нас есть список чисел: `[64, 25, 12, 22, 11]`.

**Шаг 1:**  Находим минимальный элемент среди всех — это  `11`.  
Меняем его местами с первым элементом (`64`).  
Массив после первого шага:  `[11 | 25, 12, 22, 64]`

**Шаг 2:**  Теперь ищем минимальный элемент среди оставшихся — это  `12`.  
Меняем его местами с первым элементом оставшейся части массива (`25`).  
Массив после второго шага:  `[11, 12 | 25, 22, 64]`

**Шаг 3:**  Находим минимальный элемент среди оставшихся — это  `22`.  
Меняем его местами с первым элементом оставшейся части массива (`25`).  
Массив после третьего шага:  `[11, 12, 22 | 25, 64]`

**Шаг 4:**  Находим минимальный элемент среди оставшихся — это  `25`.  
Он уже на своем месте, обмен не требуется.  
Массив после четвертого шага:  `[11, 12, 22, 25 | 64]`

**Шаг 5:**  Находим минимальный элемент среди оставшихся — это  `64`.  
Он уже на своем месте, обмен не требуется.  
Массив после пятого шага:  `[11, 12, 22, 25, 64 |]`

Теперь весь массив отсортирован:  `[11, 12, 22, 25, 64]`

## Псевдокод

    procedure SelectionSort(A, n)
	    A — список
	    n — размер  списка
	    for i = 1 to n - 1 do
		    minIndex = i
		    for j = i + 1 to n do
			    if A[j] < A[minIndex] then
				    minIndex = j
			    end if
		    end for
		    swap A[i] and A[minIndex]
	    end for
    end procedure

## Сложность
 - Время:
   -   **Лучший случай**: $O(n^2)$ — независимо от того, как отсортирован массив, алгоритм всегда будет проходить через все элементы, чтобы найти минимальный на каждом шаге.
   -   **Средний случай**: $O(n^2)$ — алгоритм всегда проходит по массиву и выполняет O(n) сравнений для каждого элемента.
   -   **Худший случай**: $O(n^2)$ — как и в среднем случае, количество сравнений остаётся одинаковым.
-   Память: $O(1)$, сортировка выполняется на месте.
